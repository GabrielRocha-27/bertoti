# ✍️ Sobre Mim

Comecei meus estudos na **Fatec** no curso de *Análise e Desenvolvimento de Sistemas (ADS)*, onde aprendi sobre linguagens de marcação como **HTML** e **CSS**, o framework **Flask** e os fundamentos de lógica de programação. Tive experiências enriquecedoras durante esse período inicial até migrar para o curso de **Banco de Dados**.

A mudança de curso foi motivada pelo desejo de me inserir mais rapidamente no mercado de trabalho e pelas orientações de professores. No curso de Banco de Dados, aprofundei meus conhecimentos em backend, linguagens de programação, gestão e manipulação de banco de dados, com foco no controle e tratamento de dados.

Durante esse período no ensino noturno, participei de duas **Maratonas Internas de Programação da Fatec**, onde nossa equipe obteve um ótimo desempenho fruto do treino e dedicação continuada.

Foi também em Banco de Dados que tive minha primeira experiência com um projeto real para um cliente externo: o **IPEM** (Instituto de Pesos e Medidas). Essa parceria entre o órgão estadual e nosso grupo de desenvolvimento resultou na entrega de um projeto de grande impacto.
